# 지도 궤적 애니메이션 렌더링 (map-animation)

> Status: Approved (2026-09-01 — 진행 지시)
> 작성일: 2026-09-01

## 1. 배경 / 현재 동작 (코드 근거)

### 1.1 기존 프로세스
- 렌더러의 intro(map_overview)는 **텍스트 카드 자리 표시자** — 이 기능이 교체 (ffmpeg-render 완료 보고)
- trips.path(LineStringZM)에 궤적 존재, EDL intro엔 bbox만 (좌표는 렌더 시 DB 조회로)
- **Mapbox 토큰 미확보** — 기획서가 대안(Headless Chromium 등)을 허용하므로 토큰 불필요 경로 채택

### 1.2 재사용 가능한 기존 인프라
- Pillow(텍스트 카드), FFmpeg 클립 파이프, MEDIA_STORAGE_ROOT, 렌더 검증 체계

## 2. 사용자 요구 (원문 요약)
기획 Phase 4: "동선이 순차적으로 그려지는 애니메이션 레이어", EDL Intro: "전체 궤적 조감도 + 타이틀". 마일스톤 4 기능 12.

## 3. 범위 / 비범위

### 범위 (In scope)
- **OSM 래스터 타일** 기반 지도 스티치(줌 자동 계산, bbox+여백) — 토큰 불필요, 타일 캐시로 재실행 네트워크 0
- 궤적 폴리라인 **점진 드로잉** 프레임 시퀀스(3s×30fps=90장, Pillow) + 시작 마커·진행 헤드 + 하단 타이틀
- 렌더러 intro 분기 교체: path 있으면 지도 애니메이션, 없으면 기존 텍스트 카드 **폴백**
- 타일 소스 추상화 — Mapbox 토큰 확보 시 URL 템플릿만 교체

### 비범위 (Out of scope)
- Mapbox 벡터 스타일/3D 틸트(토큰 후), Body 구간 이동 맵 인서트, HUD
- 타일 상용 트래픽 대책(자체 타일 서버) — 배포 시

## 4. 요구사항 상세
- OSM 타일 정책 준수: User-Agent 명시, 요청 절제(줌 산정으로 프레임당 재요청 없음 — 스티치 1회)
- 좌표→픽셀은 Web Mercator — 순수 함수로 유닛 테스트
- 라인 스타일: ui-tokens brand500(#2fa872), 두께 10px, 진행 헤드 원

## 5. 방어적 AC
- path NULL/포인트 1개: 텍스트 카드 폴백 (실패 아님)
- 타일 다운로드 실패(오프라인): failed + 사유 — 단, 캐시 히트 시 오프라인도 성공
- 재실행 멱등 (캐시 사용, 동일 프레임)
